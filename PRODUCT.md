# TaskFlow

<!-- impeccable:product-schema 1 -->

## Platform

web

## Product Purpose

A browser-local task manager for organizing personal work by status, priority and due date. This is a public portfolio project, not a collaborative service.

## Users

People reviewing work, capturing tasks, updating progress, and moving tasks between stages on desktop or phone.

## Capabilities and Constraints

Retain task creation/editing/deletion with confirmation, browser persistence, grid and draggable Kanban views, title/description search, status/priority filters, computed counters, JSON export/import with id-based merge, targeted undo, cross-tab storage updates, overdue dates, light/dark themes, keyboard shortcuts and responsive keyboard access. Preserve existing taskflow_tasks records and existing empty workspaces. Keep the dependency-free HTML/CSS/JavaScript runtime and static GitHub Pages deployment.

## Brand Commitments

TaskFlow name. English interface confirmed by the user, who replied "اختر التصميم ونفّذ بالكامل". Use the installed UI/UX Pro Max, Taste, Impeccable and 21st tools. The interface should be materially independent of NOVA's project board and the other portfolio projects.

## Evidence on Hand

Incumbent index.html, style.css, script.js and README.md. No team collaboration, cloud sync, external API, invented customer metrics or pricing. Optional sample tasks must be labeled and never replace existing data implicitly.

## Product Principles

- Priorities and deadlines answer what to do next.
- Counts derive from the same tasks the user can inspect.
- Dragging has a normal keyboard/touch status control alternative.
- Portable backups and local-only storage remain explicit.
- Invalid data and storage failure get actionable, honest feedback.
